# Portfólio acadêmico de Gerlan Silva

Site construído com [Quarto](https://quarto.org/), com os layouts nativos Solana e Trestles.

## Estrutura
- `index.qmd` — apresentação inicial
- `sobre.qmd` — biografia e formação
- `pesquisas.qmd` — pesquisas
- `publicacoes.qmd` — produções
- `projetos.qmd` — acervos e projetos independentes

## Publicação
O GitHub Actions renderiza as páginas para `docs/` a cada alteração dos arquivos Quarto. Configure **Settings → Pages → Deploy from a branch → main → /docs**.

Para executar localmente: `quarto preview`.

A foto usada provisoriamente vem do avatar público do GitHub; substituir pelo retrato fornecido antes de concluir a identidade visual.
